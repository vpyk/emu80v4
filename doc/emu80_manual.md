# Emu80 v4.0.571. Руководство пользователя

## Установка и запуск эмулятора

### Версии эмулятора

Основной и рекомендуемой для использования в большинстве случаев версией эмулятора является Qt-версия Emu80/qt, только она обладает полным набором возможностей и описана в данном руководстве. Информация о SDL/wx-версиях приведена в приложении 2.

### Системные требования и установка

Эмулятор распространяется в виде zip-архивов, содержащих бинарные сборки для платформ Windows, macOS и Linux x64. Минимальные системные требования:

- Windows XP и выше (для Qt6-сборки — Windows 10 и выше)
- macOS 10.8 Mountain Lion и выше
- Linux, 64-битные x86-дистрибутивы с поддержкой GLIBC 2.14 и GLIBCXX 3.4.21\
  (примерно с 2016 года)

Также возможна сборка эмулятора из исходников, эта процедура описана в приложении 1.

Эмулятор может работать в двух режимах — обычном и portable.

Windows- и linux-сборки по умолчанию работают _в portable-режиме_, при этом эмулятор хранит настройки в поддиректории _\_settings_ внутри своей директории. При этом эмулятор должен быть распакован в директорию, доступную для записи. Для macOS данный режим недоступен.

Если директория _\_settings_ отсутствует, эмулятор запускается _в обычном (не-portable) режиме_, и хранит настройки в профиле пользователя. При этом архив с эмулятором может быть распакован в директорию, недоступную для записи, например в «/opt» или «Program Files», однако директорию _\_settings_ после распаковки нужно удалить.

Необходимо учитывать, что в случае, если директория эмулятора недоступна для записи, некоторые поставляемые с эмулятором и автоматически подключаемые образы дисков будут недоступны для записи.

Ini-файл располагается по следующему пути:

- Portable-режим: `./_settings`
- Windows: `%USERPROFILE%\AppData\Roaming\Emu80`
- Linux и macOS: `~/.config/Emu80`

В редких случаях при возникновении проблем с запуском эмулятора из-за некорректных настроек может возникнуть необходимость удаления текущих настроек. Для этого нужно удалить ini-файл эмулятора, расположенный по одному из указанным выше путей. Под Windows для этого можно воспользоваться поставляемым в комплекте файлом `RestoreSettings.cmd`.

### Дополнительная настройка под Windows

Для удобства работы под Windows созданы два cmd-файла. Файл `AssociateFiles.cmd`, будучи запущенным из директории эмулятора, регистрирует в системе расширения файлов «rk», «rkr», «gam», «rka», «rkp», «rkm», «rk8», «rku», «rks», «rko», «bru», «ord», «cpu», «rke», «lvt», «rk4», «rkl», ассоциирует их с эмулятором и назначает им соответствующие иконки. Для отмены назначения служит cmd-файл `DeassociateFiles.cmd`.

### Запуск и параметры командной строки

Для запуска эмулятора в разных ОС следует использовать:

- Windows: файл `Emu80qt.exe`
- Linux: файл `run.sh` или `Emu80qt`
- macOS: пакет `Emu80qt.app`

Общие параметры командной строки:

```
Emu80qt [опции]
```

Доступные опции:

- **`--platform <имя платформы>`** — запуск в режиме требуемой платформы, имена платформ находятся в файле emu80.conf в секции «Platform list» строках виде «config.addPlatform =» в качестве третьего параметра (например, «rk86», «vector.z80» и т. д.)
- **`--conf-file <путь_к_cfg-файлу>`** — запуск с использованием произвольной конфигурации, определяемой указанным conf-файлом. Рекомендуется по возможности использовать вместе с опцией `--platform`, при этом указанный файл используется вместо используемого по умолчанию для данной платформы, однако в интерфейсе Qt-версии эмулятора становятся доступными специфические для данной платформы настройки.
- **`--run <загружаемый файл>`** — загрузка и запуск указанного файла. Если явно не указана используемая платформа, будет произведена попытка автоматического ее определения.
- **`--load <загружаемый файл>`** — загрузка указанного файла (без запуска). Если явно не указана используемая платформа, будет произведена попытка автоматического ее определения.
- **`--post-conf <путь_к_conf-файлу>`** — применение указанного дополнительного конфигурационного файла после загрузки основной конфигурации платформы.
- **`--disk-a <путь к образу диска>`** (также **`--disk-b`**, **`--disk-c`**, **`--disk-d`**) —подключение указанного образа дискеты после загрузки платформы.
- **`--hdd <путь к образу диска>`** — подключение указанного образа жесткого диска после загрузки платформы.
- **`--edd <путь к образу диска>`** (также **`--edd2`**) — подключение указанного образа электронного диска после загрузки платформы.

Устаревший формат параметров командной строки, оставлен для совместимости со старыми версиями:

```
Emu80qt [опции] [<загружаемый файл>]
```

Если в параметрах командной строки присутствует имя загружаемого файла, будут произведены по возможности его загрузка и запуск.

Опции:

- **`-<код_платформы>`** — запуск в режиме требуемой платформы, коды платформ можно увидеть в файле `emu80.conf` в секции «Platform list» строках виде `config.addPlatform =` в качестве последнего четвертого параметра. Например, «-r» для запуска в режиме «Радио-86РК», «-a» — в режиме Апогея и т. д. Если четвертый параметр отсутствует, то данную платформу из командной строки можно запустить только с использованием параметра `--platform` (см. выше).
- **`-l`** — только загрузить файл, без автозапуска

Если параметр кода платформы не указан, но присутствует имя файла, будет произведена попытка автоматического определения типа запускаемой платформы.

Параметры командной строки, специфичные для Qt-версии для Windows:

- **`-opengl`** — использовать OpenGL (обычно по умолчанию)
- **`-angle`** — включить режим использования DirectX вместо OpenGL. Автоматически выбирается максимальная поддерживаемая версия DirectX.
- **`-dx9`** — аналогично предыдущему, используется DirectX 9
- **`-dx11`** — используется DirectX 11
- **`-warp`** — использовать программный рендеринг DirectX 11 (не рекомендуется)
- **`-soft`** — использовать программный рендеринг OpenGL (не рекомендуется)

Также в составе window-версии поставляются cmd-файлы `Emu80qt-opengl.cmd` и `Emu80qt-dx.cmd` для запуска в режимах OpenGL и DirectX соответственно.

### WebAssembly-сборка

Встраивание эмулятора на сайт производится путем подключения iframe с эмулятором. Для этого необходимы файлы:

- `emuframe.html`
- `emuframe.js`
- `emuframe.wasm`

Также копируются файл `emu80.conf` и необходимые файлы нужных платформ из директории `dist` эмулятора.

Параметры iframe:

```html
<iframe
  src="emuframe.html?platform"
  ="...&run"
  ="...&post-conf"
  ="..."
></iframe>
```

- `platform` – имя запускаемой платформы
- `run` (опционально) – url запускаемого файла
- `post-conf` (опционально) – url conf-файла со специфическими для данной программы параметрами

Также возможно указание других параметров, в общем случае совпадающих с параметрами командной строки десктопной версии.

Пример более продвинутого управления эмулятором см. в `src/wasm/web`.

### MCP-сервер

Эмулятор может быть собран с поддержкой встроенного MCP-сервера для взаимодействия с AI-ассистентами. Готовый бинарный файл, собранный с поддержкой MCP-сервера, присутствует в Qt6-сборке для Windows под именем Emu80qt-mcp.exe. GUI-отладчик в данной сборке в настоящее время недоступен, отладка возможна только с помощью MCP-сервера. Более подробную информацию о встроенном MCP-сервере смотрите в файле документации MCP-server.md.

## Основы работы с эмулятором

Для управления эмулятором служит главное меню, часть пунктов которого также продублирована на панели инструментов. Многие действия можно выполнять с помощью «горячих клавиш», большинство их которых работают в комбинации с клавишей Alt. Alt всегда можно заменить на клавишу Meta (Win), это может быть актуально в некоторых версиях Linux. Также можно попробовать вместо Alt использовать комбинацию Alt-Shift.

При первом запуске эмулятор запрашивает желаемый тип эмулируемой платформы, в последующем для выбора другого типа компьютера используйте клавиши Alt-F9 либо соответствующую кнопку на панели инструментов.

Эмулятор имеет встроенный загрузчик, который поддерживает наиболее распространенные типы файлов для каждой платформы. Используйте комбинации клавиш Alt-F3 для загрузки и запуска наиболее распространенных типов файлов. Также для запуска файла можно использовать drag’n’drop в окно эмулятора либо передачу файла в командной строке (см. выше). В случае использования drag’n’drop необходимо предварительно переключить эмулятор в режим эмуляции необходимого компьютера.

Также эмулятор имеет включенный по умолчанию режим перенаправления обращений к магнитофону в файл. В этом режиме эмулятор при попытке обращения прикладной программы к магнитофону выдает запрос на выбор файла. В зависимости от текущей платформы может быть выбран либо файл образа ленты (\*.rk?, \*.cas и т.п.), либо wav/csw-файл.

Для большинства платформ написана краткая справка, где описаны основные моменты работы в ней и загрузки разных типов файлов, а также приведены раскладки клавиатуры. Краткая справка автоматически выдается при первом запуске, в дальнейшем ее можно вывести с помощью соответствующего пункта меню или клавиш Alt-F1.

Эмулятор поддерживает 3 режима раскладки клавиатуры. По умолчанию для большинства платформ установлена «Умная» раскладка. В этом случае текст набирается в соответствии с раскладкой PC, язык также переключается системными средствами. При необходимости могут быть также использованы раскладки qwerty и йцукен.

В эмуляторе доступны большое количество настроек отображения. Часть из них доступны через панель инструментов, часть — только в диалоге настроек. Для удобства отдельно выделено несколько пресетов, включающих в себя типичные комбинации нескольких настроек. Основные возможности настройки отображения включают: выбор коэффициента масштабирования, выбор размеров окна, режимов сглаживания, шейдеров и соотношения сторон эмулируемой платформы, режима отображения скан-линий и различных варианты работы с полукадрами. Более подробно и другие эти настройки описаны в следующем разделе.

## Меню, горячие клавиши, панель инструментов и другие настройки

В разделе описаны назначение пунктов меню, а также соответствующих им кнопок панели инструментов и горячих клавиш Qt-версии Emu80. Горячие клавиши доступны также в SDL/wx- и web-версиях эмулятора, кнопки частично присутствуют в web-версии. Большая часть пунктов меню также продублированы в диалоге настроек.

### Получение помощи (меню «Помощь»)

- **Справка по платформе**, _Alt-F1_

  Выдает основную информацию по работе с текущей выбранной платформой. Позволяет человеку, не знакомому с данным компьютером, выполнить основные операции по работе с ним, загрузить и запустить предназначенные для него программы. Также, как правило, содержит подсказки по соответствию клавиш клавиатуры PC и эмулируемой платформы.

- **О программе**

  Выводит диалоговое окно с информацией о текущей версии эмулятора. Также выдается техническая информация о сборке в формате:

  Версия Qt / компилятор / ОС / архитектура / платформа / стиль

### Работа с файлами (меню «Файл»)

- ![Загрузить и выполнить](images/icons/open_run.png) **Загрузить и выполнить**, _Alt-F3_

  Позволяет загрузить и попытаться выполнить файлы для текущей платформы с помощью встроенного загрузчика эмулятора. Конкретный набор поддерживаемых форматов файлов зависит от конкретной платформы.

- ![Загрузить](images/icons/open.png) **Загрузить**, _Alt-L_

  Позволяет загрузить в память файл без выполнения. Конкретные действия зависят от платформы, где-то происходит загрузка в память, где-то — в электронный диск и т.п.

- ![Открыть wav](images/icons/open_wav.png) **Открыть wav**, _Alt-W_

  Открывает wav-файл и запускает его на воспроизведение, во время воспроизведения файла возможна его загрузка с магнитофона средствами эмулируемой платформы. Для остановки воспроизведения нужно повторить эту команду.

- ![Диск A](images/icons/disk_a.png) ![Диск B](images/icons/disk_b.png) ![Диск C](images/icons/disk_c.png) ![Диск D](images/icons/disk_d.png) **Диск A (B, C, D)**, _Alt-A … Alt-D_

  Доступны в конфигурациях, использующих дисковод. Монтирует образ диска на соответствующий дисковод. Дисководы со смонтированными образами отображаются буквой зеленого цвета, с отключенными образами — красного (![Диск A без образа (красная буква)](images/icons/disk_a_off.png)). Для отключения образа служит пункт меню _«Извлечь диск»_. Также можно установить опции _«Защита записи»_ и _«Автоматически подключать при запуске»_, чтобы не подключать нужный образ каждый раз при запуске эмулятора. Опция «Защита записи» устанавливается по умолчанию для диска «A» для исключения случайной записи на диск, при необходимости ее можно снять.

- ![HDD](images/icons/hdd.png) ![HDD с подключённым образом (зелёная точка)](images/icons/hdd_on.png) **HDD**, _Alt-Shift-H_

  Загрузить образ жесткого диска с интерфейсом IDE либо CompactFlash-карты. Доступны в конфигурациях, поддерживающих данный интерфейс. На данный момент реализована поддержка только одного диска. Работа с данным пунктом меню аналогична работе с образами дискет (см. выше). Обратите внимание, что работа с образами SD-карт исторически настраивается в меню конфигурации платформы (Alt-F8).

- ![EDD](images/icons/edd.png) ![EDD2](images/icons/edd2.png) **EDD** (_Alt-E_)**, EDD2**

  Доступны в конфигурациях, поддерживающих электронный диск. Загружают из файла содержимое электронного диска и сопоставляют его с файлом. Диски, сопоставленные с файлом образа, отмечаются зеленой точкой (![EDD с назначенным образом (зелёная точка)](images/icons/edd_on.png)). В меню данного пункта также доступны опции:
  - _Сохранить_ — сохраняет текущее содержимое диска в сопоставленный образ
  - _Сохранить как_ — сохраняет содержимое диска в произвольный файл
  - _Отменить назначение_ — отменяет назначение образа
  - _Автозагрузка_ — запоминает назначенный образ и автоматически загружает из него диск при запуске
  - _Автосохранение при выходе_ — автоматически сохраняет содержимое диска в образ при выходе.

- **Выход**, _Alt-X_

  Производит выход из эмулятора.

### Общее управление эмуляцией (меню «Платформа»)

- ![Платформа](images/icons/computer.png) **Платформа**, _Alt-F9_

  Может работать как кнопка при нажатии или как подменю при выборе значка со стрелкой. При использовании как кнопки или через горячую клавишу выдается окно выбора доступных конфигураций различных платформ. Основные (рекомендуемые для новичков) варианты конфигураций выделены жирным шрифтом. При использовании как меню перечень доступных конфигураций представляется в виде иерархического меню, в котором также доступен выбор последних используемых платформ. Иногда может быть полезно выбрать последнюю использованную платформу для ее холодного рестарта с очисткой памяти, для этого достаточно нажать _Alt-F9, Enter_.

- ![Конфигурация платформы](images/icons/config.png) **Конфигурация платформы**, _Alt-F8_

  Вызывает окно дополнительной настройки аппаратной конфигурации платформы, доступна не для всех платформ. Изменения требуют перезапуска текущей платформы уже с новой конфигурацией. Данная опция недоступна в SDL и web-версиях.

- ![Сброс](images/icons/reset.png) **Сброс**, _Alt-F11_

  Выполняет сброс текущей платформы аналогично реальному сбросу эмулируемой платформы. Память специально не очищается, устройства, которые не сбрасываются на реале, также не сбрасываются, поэтому в случае нештатных ситуаций может понадобиться повторно выбрать платформу, что равноценно выключению и включению. Кроме этой опции для некоторых платформ могут быть реализованы отдельные варианты сброса, назначенные на отдельные клавиши.

- ![Пауза](images/icons/pause.png) **Пауза**, _Alt-P_ или _Pause_

  Приостанавливает эмуляцию, для продолжения работы следует повторно выбрать данный пункт. В режиме паузы могут не срабатывать некоторые опции изменения режима отображения; новые значения в таком случае будут применены при снятии с режима паузы.

- ![Ускорение](images/icons/forward.png) **Ускорение**, _End_

  Включает ускорение работы эмулятора в 4 раза, работает только во время нажатия, фиксации не имеет.

- **Увеличить скорость**, _Alt-PgUp_

- **Уменьшить скорость**, _Alt-PgDn_

  Увеличение и уменьшение скорости эмуляции. Каждые 3 нажатия изменяют скорость в 2 раза. Максимальное значение скорости — 16x (12 нажатий).

- **Увеличить скорость (точн.)**, _Alt-Up_

- **Уменьшить скорость (точн.)**, _Alt-Dn_

  Более плавные увеличение и уменьшение скорости эмуляции. Скорость изменяется в 2 раза за 12 нажатий.

- **Нормальная скорость**, _Alt-Home_

  Восстанавливает нормальную скорость эмуляции

- ![Полная скорость](images/icons/full_throttle.png) **Полная скорость (врем.)**, _Alt-Del_

- ![Полная скорость](images/icons/full_throttle.png) **Полная скорость (фикс.)**, _Alt-End_

  Включают эмуляцию со скоростью, близкой к максимальной. Первый вариант (Alt-Del) работает, пока нажата соответствующая кнопка или комбинация клавиш, второй работает с фиксацией, для выключения максимальной скорости нужно повторно нажать Alt-Del либо другую комбинацию клавиш, управляющую скоростью (например, расположенную рядом клавишу End).

- ![Отладчик](images/icons/debug.png) **Отладчик**, _Alt-D_

  Останавливает выполнение и вызывает встроенный отладчик.

### Настройки

- ![Настройки эмулятора](images/icons/settings.png) **Настройки эмулятора**, _Alt-F12_

  Вызывает окно настроек эмулятора, содержащее как некоторые настройки, доступные через меню, так и расширенные. Расширенные настройки, недоступные через меню, будут описаны ниже в этом разделе.

- ![Раскладка клавиатуры](images/icons/keyboard.png) **Раскладка клавиатуры**

  При нажатии на кнопку позволяет через подменю выбрать один из трех вариантов раскладки, доступных также непосредственно через горячие клавиши:
  - **Qwerty**, _Alt-Q_
  - **Йцукен**, _Alt-J_
  - **«Умная»** или **Smart-раскладка**, _Alt-K_

  В большинстве клавиатур советских компьютеров пары русских и латинских букв расположены на клавишах не так, как на современных. При этом Qwerty-раскладка соответствует современному расположению латинских букв, а Йцукен — русских. «Умная» раскладка позволяет набирать текст так, как обычно на ПК, при этом эмулятор самостоятельно переключает регистр и/или алфавит. Однако, она реализована не для всех платформ и не везде одинаково хорошо работает. Посмотреть подсказку по расположению клавиш для текущей платформы в разных раскладках можно в справке по платформе (Alt-F1). По умолчанию установлена опция Smart для тех платформ, где она полноценно работает и Qwerty — для остальных.

- ![Захват печати](images/icons/printer.png) **Захват печати**, _Alt-Shift-P_

  Запрашивает имя файла, в который будет перенаправляться отправляемая на принтер информация и включает режим перехвата информации, отправляемой на печать. Доступна в конфигурациях, поддерживающих принтер.

- ![Перехват магнитофона](images/icons/tape.png) **Перехват магнитофона**, _Alt-T_

  При включенной опции эмулятор перехватывает обращения программ к магнитофону и перенаправляет их в файл, выводя в нужные моменты запросы на открытие либо сохранение файла. При отключенной опции возможен ввод только путем явного проигрывания wav-файла. Перехват должен работать в большинстве случаев, однако невозможно предусмотреть все варианты, поэтому для некоторых программ перехват может не работать. По умолчанию опция включена.

- ![Не воспроизводить звук с магнитофона](images/icons/mute_tape.png) **Не воспроизводить звук с магнитофона**

  По умолчанию эмулятор воспроизводит звук, выводимый на магнитофон. Однако, на некоторых платформах (например, на Специалисте), в процессе работы на магнитофонном выходе могут возникать посторонние звуки, данная опция позволяет их отключить.

- ![Режим цвета](images/icons/colormode.png) **Режим цвета**, _Alt-C_

  Позволяет выбрать один из доступных для конкретной платформы режимов цвета. При нажатии на кнопку либо выборе сочетания клавиш Alt-C происходит циклическая смена режимов, при нажатии на стрелку можно непосредственно выбрать нужный режим из меню. Текущий режим отображается в статусной строке в нижней части окна. Разные режимы цвета соответствуют либо разным вариантам компьютеров или их видеоадаптеров, либо разным выходам компьютеров (цветной и черно-белый).

- ![Видимая область](images/icons/crop.png) **Видимая область**, _Alt-V_

  Информация, выдаваемая видеоадаптерами различных компьютеров, в общем случае может как занимать только часть экрана телевизора или монитора, так и, наоборот, выходить за пределы обычно отображаемой области. Включенная опция позволяет увидеть именно ту часть изображения, которая в соответствии с телевизионными стандартами должна отображаться на экране ТВ. При этом активная часть изображения может быть как расширена за счет добавления бордюров, так и обрезана путем скрытия фрагментов, попадающих в области гашения развертки.

- ![Соотношение сторон](images/icons/aspect.png) **Соотношение сторон**, _Alt-R_

  Позволяет включить режим, в котором строго выдерживается соотношение сторон изображения эмулируемой платформы, как оно отображается на стандартном устройстве (ТВ или мониторе). При этом коэффициент масштабирования изображения по горизонтали практически всегда получается дробным, что может повлиять на качество изображения в зависимости от режимов сглаживания. С выключенной опцией всегда используются целочисленные коэффициенты, однако изображение может быть несколько сжатым или растянутым. В диалоге настроек доступны дополнительные настройки для этих двух режимов, позволяющие более тонко настроить желаемый вид изображения.

- ![Широкоэкранный режим 16:9](images/icons/wide.png) **Широкоэкранный режим (16:9)**, _Alt-N_

  При включенной опции реального соотношения сторон (см. выше) управляет тем, какой ТВ или монитор эмулируется — 4:3 (5:4) или 16:9.

- ![Нет сглаживания](images/icons/sm_nearest.png) ![Границы пикселей](images/icons/sm_sharp.png) ![Билинейное сглаживание](images/icons/sm_bilinear.png) ![Шейдер](images/icons/shader.png) **Сглаживание/постобработка**

  Данная опция выбирает способ обработки изображения при масштабировании окна, особенно актуальных при выборе реального соотношения сторон. Доступны следующие варианты:
  - ![Нет сглаживания](images/icons/sm_nearest.png) _Нет сглаживания_

    В результате масштабирования не происходит корректировки цвета пикселей, масштабированные пиксели могут иметь разный размер.

  - ![Билинейное сглаживание](images/icons/sm_bilinear.png) _Билинейное_

    При масштабировании производится билинейная фильтрация изображения. Результирующее изображение выглядит гладким, но может быть излишне размытым, особенно при большом увеличении.

  - ![Границы пикселей](images/icons/sm_sharp.png) _Границы пикселей_

    Компромисс между предыдущими вариантами, билинейная фильтрация производится только на границе пикселей, в случае целочисленного масштабирования никак не проявляется. Данная опция выбрана по умолчанию. На слабых машинах может потребовать больше ресурсов видеокарты или процессора, чем предыдущие варианты. Более качественным вариантом данной опции является шейдер _pixellate_ (см. ниже).

  - ![Шейдер](images/icons/shader.png) **Шейдер**

    Использование пользовательского шейдера, предварительно выбранного с помощью пункта меню «Шейдеры» (см. ниже).

  - **Убрать цвет**

    Данная опция активирует специальный шейдер, позволяющий получить черно-белое изображение из любого цветного. Опция не зависит от режима цвета конкретного компьютера, и работает на более позднем этапе, убирая цвет из любого цветного изображения.

  - ![Шейдер](images/icons/shader.png) **Шейдеры**

    Выбор пользовательского шейдера. Шейдеры ищутся в поддиректории shaders в директории эмулятора. Используются старый упрощенный формат шейдеров проекта libretro. Для работы могут потребовать более мощной видеокарты, чем достаточно для трех обычных опций. В составе эмулятора поставляются следующие адаптированные шейдеры:
    - _advinterp3x_ — сглаживание пиксельной структуры изображения
    - _crt-geom_ - имитация ЭЛТ-монитора, с искривлением геометрии
    - _crt-geom-dynamic_ - то же, что _crt-geom_, но с дополнительными динамическими искажениями
    - _crt-hyllian_ — еще одна имитация ЭЛТ-монитора, без искривления
    - _pixellate_ — аналог сглаживания границ пикселей, однако учитывает гамму цветового пространства sRGB, и работает более точно: например, позволяет без муара масштабировать шахматную заливку и т. п.
    - _uniform-nearest_ — способ сглаживания, учитывающий субпиксели ЖК-монитора

    Кроме того, специально для emu80 был разработан набор шейдеров emu80-bwcrt-\*, имитирующих распространенные в советское время черно-белые телевизоры и мониторы
    - _emu80-bwcrt_ — основной вариант
    - _emu80-bwcrt-sharp_ — более четкое изображение
    - _emu80-bwcrt-warp_ — с искривлением
    - _emu80-bwcrt-nobg_ — без подсветки фона

    Можете выбрать наиболее подходящий для себя вариант

    В тексте каждого шейдера, как правило имеются параметры, настройкой которых можно менять результат его работы. Emu80 не поддерживает изменение параметров из интерфейса эмулятора, но при желании можно изменить их внутри текста самого шейдера. Также можно добавить свой шейдер, просто разместив файл поддерживаемого формата \*.glsl в директории shaders.

    Многопроходные шейдеры на данный сосент не поддерживаются.

- ![Шрифт](images/icons/font.png) **Шрифт**, _Alt-F_

  Параметр доступен для большинства платформ, использующих контроллер ЭЛТ ВГ75. Включенная опция меняет используемый шрифт на более красивый формата 8×16 (или 8×12 в зависимости от параметров экрана).

- ![Без звука](images/icons/mute.png) **Без звука**, _Alt-M_

  Позволяет временно отключить звук в эмуляторе.

- ![1x](images/icons/1x.png) … ![5x](images/icons/5x.png), ![Изменяемый размер окна](images/icons/resizable.png), ![384](images/icons/384.png) … ![1080](images/icons/1080.png) **Размер окна**

  Позволяет выбрать предустановку, задающую размер окна эмулятора.
  - ![1x](images/icons/1x.png) … ![5x](images/icons/5x.png) **1x, 2x, 3x, 4x, 5x** (_Alt-1, Alt-2, Alt-3, Alt-4, Alt-5_), **1.5x и 2.5x** (_Alt-8 и Alt-9_)

    Данные опции задают размер окна эмулятора, соответствующий выбранному фиксированному коэффициенту масштабирования по вертикали. Коэффициент масштабирования по горизонтали при этом зависит от режима точного соотношения сторон.

  - ![Изменяемый размер окна](images/icons/resizable.png) **Изменяемый**, _Alt-0_

    Опция изменяемого пользователем размера окна позволяет пользователю самостоятельно изменять размер окна. При этом в режиме точного соотношения сторон изображение панорамируется, так, что слева-справа или сверху-снизу добавляются пустые поля, а при выключенном режиме точного соотношения сторон изображение растягивается на все окно.

  - ![384](images/icons/384.png) … ![1080](images/icons/1080.png), **576×486 … 1920×1080**

    Опции от 576×486 до 1920×1080 позволяют установить фиксированный размер окна эмулятора из перечня типичных разрешений.

- **Полноэкранный режим**, _Alt-Enter_

  Переводит эмулятор в полноэкранный режим работы. Разрешение экрана при этом не меняется, рабочая область эмулятора заполняет весь экран. Выход из полноэкранного режима — повторное нажатие Alt-Enter. В полноэкранном режиме может оказаться полезной опция Alt-R, управляющая соотношением сторон (см. выше).

- **Полнооконный режим**, _Alt-\\_

  Скрывает в окне эмулятора области меню, панели инструментов и статусной строки, оставляя рабочую область во все окно. Выход из режима — повторное нажатие Alt-\\. Опция доступна только в Qt-версии эмулятора.

- ![Сделать скриншот](images/icons/screenshot.png) **Сделать скриншот**, _Alt-H_

  Сохраняет скриншот экрана эмулируемого компьютера в формат BMP или PNG. Размер изображения и применяемые фильтры зависят от текущих настроек отображения.

- **Копировать экран**, _Alt-Ins_

  Аналогично предыдущему пункту, но скриншот сохраняется в буфере обмена.

- **Копировать текстовый экран**, _Alt-Shift-Ins_

  Доступно на некоторых платформах с алфавитно-цифровым видеоконтроллером. Копирует в буфер обмена информацию на экране в текстовом виде. При этом символы, отсутствующие в кодировке Unicode, заменяются близкими по начертанию.

- **Вставить текст**, _Alt-Shift-V_

  Доступно на некоторых платформах с работающей Smart-раскладкой клавиатуры. Позволяет вставить текст из буфера обмена, имитируя нажатия клавиш. На время вставки происходит ускорение работы эмулятора.

### Дополнительные настройки в окне настроек, отсутствующие в меню

- Вкладка «Система»
  - _Язык_

    Позволяет выбрать язык интерфейса эмулятора. В эмулятор встроены два языка — русский и английский, дополнительные локализации ищутся в поддиректории translations в директории эмулятора. При выборе языка системы и отсутствии для него локализации по умолчанию устанавливается английский. Некоторые строки, размещенные в конфигурационных файлах (фильтры имен файлов и т. п.) не локализуются.

  - _Показывать подсказку по платформе при запуске_

    Позволяет автоматически выводить подсказку по платформе при каждом запуске. В дальнейшем подсказку можно посмотреть с помощью комбинации клавиш Alt-F1 или соответствующего пункта меню. Отключить автоматическое отображение подсказки можно как в меню настроек, так и в самом окне справки.

  - _Стиль Fusion_

    Устанавливает стиль _Fusion_ для отображения пользовательского интерфейса эмулятора. Данная настройка обеспечивает одинаковый внешний вид эмулятора в любых операционных системах. Под Windows необходима для использования темной темы, если таковая установлена в настройках интерфейса Windows. Если Fusion не используется, то внешний вид интерфейса может зависеть от ОС и настроек интерфейса в ней.

  - _V-Sync_

    Включение привязки к системной частоте обновления экрана. Включение опции может помочь избежать в некоторых случаях эффекта тиринга на экране. Однако, иногда включенная опция может вызывать проблемы со звуком (треск), обычно это наблюдается на видеокартах AMD с относительно старыми драйверами, тогда ее лучше выключить.

  - _Ограничение FPS_

    Позволяет искусственно ограничить частоту обновления экрана, может быть полезно на старых компьютерах для повышения быстродействия.

  - _Частота дискретизации_

    Определяет используемую частоту дискретизации звука. Значение по умолчанию 48000 обычно оптимально, увеличение до 96000 может уменьшить лаг между изображением и звуком, однако при этом системный микшер ОС также должен работать на аналогичной или более высокой частоте.

  - _Громкость_

    Значение громкости от 1 до 7. Значение по умолчанию 6 соответствует максимальной громкости без искажений. Значение 7 может вызвать артефакты звука в некоторых случаях.

  - _Отображать только выбранные платформы_

    Позволяет отключить отображение не актуальных для пользователя платформ в списке доступных.

- Вкладка «Окно»

  Данные настройки позволяют более тонко управлять параметрами размера окна и соотношения сторон, чем соответствующие пункты меню и горячие клавиши.
  - _Размер окна_

    Устанавливается отдельно для каждой платформы. Позволяет выбрать один из трех вариантов:
    - _Автоматически устанавливаемый_. Размер окна устанавливается автоматически при изменении разрешения в соответствии с коэффициентом масштабирования (см. ниже), пользователь не может изменить размер окна самостоятельно с помощью мыши.
    - _Изменяемый пользователем_. Пользователь сам может устанавливать желаемый размер окна с помощью мыши. Также для этого режима доступна опция «_Сохранять размер окна_», при ее включении размер окна запоминается и восстанавливается при следующем запуске эмулятора.
    - _Фиксированный_. Размеры окна фиксированы и задаются в пикселях в соответствующих полях, пользователь не может изменять размер окна.

  - _Масштабирование_

    Доступны 3 варианта:
    - _Фиксированный масштаб_. Доступны 7 вариантов от 1x до 5x с промежуточными значениями в 1.5x и 2.5x. Изображение автоматически масштабируется и отображается в окне с центрированием. Если размера окна недостаточно, то края изображения обрезаются, в противном случае добавляются поля.
    - _Растянуть во все окно_. Пункт доступен в режимах без автоматической установки режима окна. Изображение масштабируется так, чтобы заполнить все окно либо его часть, если включено соблюдение соотношения сторон (см. ниже).
    - _Вписать в окно с целым масштабом_. Выбирается максимальный целочисленный коэффициент масштабирования, при котором изображение целиком помещается в окно.

  - _Точное соотношение сторон_

    Переключает режим соблюдения точного соотношения сторон (PAR) эмулируемого компьютера. Для включенного и выключенного режима доступны отдельные настройки:

    Настройки для включенного режима точного соотношения сторон:
    - _Формат экрана — 4:3 или 16:9_, определяет вид эмулируемого ТВ для отображения.
    - _Пользовательский формат_ — позволяет задать свой формат соотношения сторон монитора.

    Выключенный режим точного соотношения сторон
    - _Адаптивный режим_ — выбираемый пользователем коэффициент масштабирования определяет масштабирование по вертикали, целочисленный коэффициент масштабирования по горизонтали подбирается автоматически таким образом, чтобы максимально близко соответствовать требуемому соотношению сторон.
    - _Квадратные пиксели_ — коэффициенты масштабирования по вертикали и горизонтали совпадают, всегда отображаются квадратные пиксели.

  - _Серый фон_

    При включенной опции поля окна, не занятые изображением, закрашиваются серым цветом, что позволяет легко выделить активную область.

- Вкладка «Экран»
  - _Смешивать полукадры_

    Определяет, как эмулятор отображает последовательные полукадры изображения. Настройка может быть полезна для gigascreen-эффекта и т.п. Доступные варианты:
    - _Выкл._ Не смешивать полукадры. Каждый полукадр интерпретируется как самостоятельный кадр. Gigascreen отображается в виде поочередного отображения разных цветов, вызывая мерцание, как в оригинале. Однако, мерцание будет относительно равномерным только при использовании FreeSync/G-Sync или просто на мониторах с высокой частотой кадров.
    - _Смешивать_. Соседние полукадры смешиваются и усредняются с учетом гаммы sRGB. Данный режим при отображении gigascreen дает немерцающее изображение, наиболее близкое по цвету к реальному.
    - Усреднять (старый метод). Полукадры смешиваются без учета гаммы sRGB. Также дает немерцающую картинку, однако, как правило, более темную, чем на реальном ЭЛТ. Оставлен для совместимости.
    - Чересстрочное отображение. Скан-линии четных и нечетных полукадров отображаются в виде четных и нечетных строк итогового изображения, количество строк растра удваивается. Gigascreen будет показан в «полосатом» виде.
    - Эмуляция линий растра. Каждый полукадр также интерпретируется как самостоятельный кадр, однако за счет удвоения количества линий растра, как и в предыдущем варианте, имитируется отображение скан-линий ЭЛТ-монитора. Для более продвинутой имитации ЭЛТ-монитора рекомендуется использовать шейдеры.

- Вкладка «Отладчик»
  - _Выйти в отладчик по команде HLT/недокументированным командам ВМ80_

    В случае, если во время выполнения кода ВМ80 встречается инструкция HLT или недокументированная инструкция соответственно, автоматически происходит выход в отладчик. Для процессора Z80 игнорируется.

  - _Мнемоники 8080/Z80 в верхнем регистре_

    Позволяет управлять регистром отображения мнемоник процессоров 8080 и Z80 соответственно.

  - _Использовать мнемоники Z80 для 8080_

    Позволяет использовать мнемоники Z80 даже при отладке кода 8080. Аналогичная опция есть в самом отладчике, но данная настройка носит постоянный характер и запоминается между запусками эмулятора.

  - _F5 и F9 наоборот (как в VS)_

    При установленной опции клавиша F5 запускает программу на выполнение, а F9 — устанавливает точку останова. При снятой — назначения клавиш меняются местами.

  - _Таблица символов_

    Позволяет задать одну из двух таблиц символов, отображаемых в символьной части дампа памяти — _РК86 (КОИ-7 Н2)_ и _КОИ-8_. Значение по умолчанию соответствует обычно применяемой в соответствующей платформе кодовой таблице, но в некоторых случай может оказаться удобным задать таблицу символов явно.

  - _Сброс нажатых клавиш при покидании отладчика_

    В случае, если выход в отладчик происходит, когда нажата какая-либо клавиша, событие отжатия может потеряться, и тогда после выхода из отладчика эта клавиша «залипает». Опция позволяет принудительно сбрасывать все нажатые клавиши при выходе из отладчика и избегать таким образом «залипания». Однако, при отладке работы с клавиатурой может оказаться необходимым эту опцию отключить.

- Вкладка «Магнитофон»
  - _Канал стерео-wav-файла_

    Позволяет выбрать, какой канал — левый, правый или микс — использовать при проигрывании wav-файла. В случае выбора моно-файла настройка игнорируется.

  - _Ускорение при воспроизведении wav_

    Во всех случаях, когда происходит воспроизведение wav-файла, работа эмулятора ускоряется в указанное число раз. Настройка позволяет ускорить длительные процессы загрузки с магнитофона.

  - _Подавлять запрос файла по сбросу_

    Настройка для компьютеров, которые при сбросе сразу пытаются загружать файл с магнитофона (Специалист etc.) Включенная опция блокирует запрос выбора файла сразу после сброса.

  - _Загружать мультиблочные файлы_

    Если при загрузке файла с помощью встроенного загрузчика был прочитан не весь файл, то с включенной опцией считанный на первом этапе загрузчик может продолжить загрузку из того же файла уже с помощью механизма перехвата магнитофонных операций. Актуально для некоторых платформ, например, ПК Львов.

- Вкладка «Разное»
  - Быстрый сброс

    Опция доступна для некоторых платформ. Позволяет пропустить при сбросе длительную инициализацию и сразу перейти к работе.

Не описанные в данном разделе настройки из окна настроек эмулятора аналогичны описанным ранее пунктам меню, информацию по ним смотрите в предыдущих разделах.

## Работа с отладчиком

Запуск отладчика производится с помощью клавиш _Alt-D_ или соответствующего пункта меню. Основные возможности отладчика:

- Поддержка инструкций и мнемоник i8080 и Z80
- Управление с помощью клавиатуры и мыши
- Возможность перехода к следующей инструкции с заходом в подпрограмму и без, выполнения до текущей строки, пропуска текущей инструкции, установки точек останова по выполнению
- Редактирование доступной процессору в данный момент памяти, регистров, и флагов
- Отображение информации о времени исполнения в тактах процессора по ходу отладки
- Отображение информации о состоянии некоторых внешних устройств: ВГ75, ВТ57, ВГ93, квазидисков Вектора и т. д.
- Сохранение дампа памяти в файл

Не поддерживаются на данный момент:

- Ассемблирование команд
- Точки останова по доступу к данным
- Редактирование произвольных банков памяти, недоступных в данный момент процессору
- Чтение отладчиком регистров устройств, находящихся в общем адресном пространстве, может помешать нормальному выполнению программы

- Поддерживается первый джойстик в режиме совмещения с клавишами клавиатуры и в отдельном режиме.

- Поддержка AY-3-3910 на портах 14 и 15 по схеме Mick.
- В эмуляторе реализована ограниченная поддержка вейтов. Длительности команд приведены в соответствие с результатами, полученными _ivagor_. Дробные длительности при выполнении из ПЗУ округлены до целых тактов. В режимах 0/UNDC, если команда начинается на бордюре и заканчивается в активной области или наоборот, длительность команды берется по началу. Ситуации, когда в разных циклах идет обращение к разным типам памяти, не обрабатываются, предполагается, что операнды всегда в ОЗУ.

  - Остальные буферы и палитра — с точностью до 2-х скан-линий (может быть опережение на 1 скан-линию)
  - Режим экрана - с точностью до кадра (некоторые параметры - до скан-линии)

- Встроенный загрузчик позволяет загружать двоичные файлы и токенизированные файлы Бейсика в форматах lvt (в том числе с оверлеями - lv0, lv1 и т.д.), а также файлов образов состояния sav. Кроме того, поддерживается загрузка файлов в стандарте MSX cas, в том числе мультиблочная (в этом случае основная программа с оверлеями располагается в единственном cas-файле).
- Путем перехватов обращений к магнитофону также поддерживаются чтение и запись lvt/cas-файлов, в том числе с оверлеями (запись оверлеев работает, но я не знаю софта, который бы это использовал ;)
- Ввиду невозможности обеспечить реальные тайминги и привязку к ходу луча, эмуляция хода луча ЭЛТ пока не реализована.

### ПК8020 Корвет

- Поддержка подключения образов четырех дисков.
- На данный момент отсутствует поддержка последовательных интерфейсов и джойстика.
- Точность синхронизации растра — одна скан-линия.
- В соответствии с документацией реализовано добавление двух тактов ожидания при обращении к портам ввода-вывода.
- Реализованы прерывания от экрана, таймера и одновибратора управления мотором НГМД, однако из-за несколько неполной эмуляции ВИ53 практическое применение прерывания таймера пока затруднительно.
- Режим эмуляции выхода черно-белого изображения.
- Полноценная поддержка smart-раскладки клавиатуры, включая переключение языка.
- Поддержка магнитофона, работа с cas-файлами.
- Реализован режим быстрого сброса с пропуском начальных тестов.
- Для сброса совместно с нажатыми клавишами (Fx) используйте F11
- Опция для переназначения стрелки вниз на Numpad 5.
- Поддержка AY-3-3910 на портах ВВ55.

### Башкирия-2М

- Опция для переназначения стрелки вниз на Numpad 5.
- ВВ51 полноценно не поддерживается, его поддержка выполнена в минимальном объеме, необходимом для работы основных программ
- На данный момент нет поддержки работы с магнитофоном

Основа реализации данного ПК в Emu80 была выполнена Дмитрием Целиковым (aka b2m). К сожалению, схема данного компьютера отсутствует, поэтому нет уверенности в точной реализации его особенностей.

### ZX Spectrum

Emu80 имеет поддержку ZX Spectrum в конфигурациях 48K, 128K и Pentagon 128K:

- В настоящее время нет поддержки contended memory, поэтому бордюрные эффекты и мультиколор корректно работают только в конфигурации Pentagon. По той же причине для конфигураций 48К и 128K бордюрные эффекты работают только на верхнем бордюре.
- Поддержка TR-DOS и BDI.
- Поддержка AY и Turbo Sound.
- Поддержка General Sound в конфигурации с объемом памяти 1 Мб и частотой процессора 12 МГц.
- Для tap и tzx-форматов файлов поддерживается только flash-загрузка, tzx-файлы поддерживаются только со стандартными блоками. Сохранение возможно только в стандартном формате в tap-файлы. Ввод и (с ограничениями) вывод файлов нестандартных форматов либо с собственными загрузчиками возможен только с использованием wav или csw-файлов.

### Байт

ПК «Байт» является клоном ZX Spectrum 48K с дополнительными расширениями. В Emu80 реализована частичная поддержка расширений этого ПК:

- Поддержка таймера ВИ53 и генерации с его помощью звука
- Частичная поддержка системы защиты от копирования Церикопик

Не реализованы:

- Режим совместимости
- Биты 5 и 7 порта клавиатуры
- Contended-память и точные тайминги

Информацию по этому ПК и программы для него можно найти на сайте <https://zxbyte.ru>. Программы для загрузки в Emu80 необходимо использовать со снятой защитой, причем, если для первой версии защиты Церикопик (наборы 1 и 2) можно загружать непосредственно tzx, то для более поздних наборов возможна загрузка только wav (также со снятой защитой).

### Океан-240.2

- Поддержка двух аппаратных конфигураций — с клавиатурой-терминалом и клавиатурой МС7007.
- Поддержка двух цветовых схем — оригинальной, реализованная в известных экземплярах, а также журнальной, соответствующей схеме, опубликованной в журнале МПСИС.
- Поддержка 7 конфигураций эмулятора с разными аппаратными конфигурациями и версиями ПЗУ.
- Поддержка дисковода и RAM-диска.

На данный момент пока не реализованы:

- Перепрограммирование палитры в пределах скан-линии
- Работа с магнитофоном
- Последовательный интерфейс ВВ51
- Работа с принтером

### ВИ53

- Не поддерживается режим 5, нет поддержки счета в BCD-формате.
- Воспроизведение звука методом ШИМ.

### ВГ75

- Довольно полная реализация, не реализован только режим с удвоенной высотой строк. Не совсем правильный момент установки флага IR.
- Поддержка светового пера. Коррекция положения реализована и проверена только для Кристы.

### AY-3-3910

- Насколько возможно полная реализация звукового генератора.

### ВН59

- Работа контроллера прерываний реализована достаточно полно, но хорошо протестирована только в объеме, необходимом для работы ПК «Корвет».

## Приложение 1. Сборка из исходников

### Сборка под Linux.

Исходный текст эмулятора размещен в репозитории GitHub по адресу:

<http://github.com/vpyk/emu80v4>

Требования:

- Qt v. 5.6 и выше (для Qt-версии)

Порядок установки:

```console
$ git clone https://github.com/vpyk/emu80v4.git
$ cd emu80v4
$ qmake src/Emu80qt.pro
$ make
$ make install
```

В зависимости от дистрибутива Linux и желаемой версии Qt, необходимая версия qmake может содержаться в нем под именем qmake-qt5, qmake6 и т.п.

Установка по умолчанию производится в portable-варианте в поддиректорию `emu80` в домашней директории пользователя: `~/emu80`, при необходимости можно переместить в другое место, например, в /opt.

Также для сборки можно использовать файл проекта `src/Emu80qt.pro` для Qt Creator.

### Сборка под Windows и macOS

Для сборки под Windows и macOS предлагается использовать Qt Creator и файл проекта src/Emu80qt.pro.

## Приложение 2. SDL/wx-версии

Кроме Qt-версии, доступны еще два варианта сборки эмулятора: SDL/wx-версия и Lite-версия.

SDL/wx-версия зависит от библиотек SDL2 и wxWidgets, может быть использована на системах, где недоступен Qt или OpenGL. Обладает ограниченными возможностями по сравнению с Qt-версией. Основным режимом управления в этой версии эмулятора является использование «горячих клавиш». Горячие клавиши совпадают с используемыми в Qt-версии, для получения быстрой подсказки по ним используйте Alt-F1, для вызова окна настроек — Alt-F12. Данная версия требует обязательной установки в директорию, доступную на запись, так как настройки записываются в .opt- и .run-файлы в директории эмулятора.

Lite-версия зависит только от библиотеки SDL2, полностью лишена графического интерфейса (кроме диалогов открытия файлов) и требует для работы готовых .opt-файлов, созданных в SDL/wx-версии, параметров командной строки, а также при необходимости ручного конфигурирования файлов описания платформ (приложение 3).

Описание сборки SDL/wx- и Lite-версий из исходников приведено в `readme.md` в репозитории проекта на github. Для Windows доступна готовая бинарная сборка. Для macOS данные версии недоступны.
