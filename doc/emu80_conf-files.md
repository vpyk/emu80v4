# Приложение 3. Формат конфигурационных файлов

_Emu80 v4.0.534. Руководство пользователя_

## Синтаксис

Обычно пользователь не должен изменять конфигурационные файлы, однако при необходимости модифицировать существующие платформы это можно сделать. Также редактирование конфигурационных файлов может оказаться необходимым при использовании SDL/wx- и Lite-версий эмулятора. В данном разделе приведены основные сведения, необходимые для этого.

### Общие сведения

Эмулятор содержит два вида конфигурационных файлов:

- `emu80.conf` – файл общих настроек эмулятора, находится в той же папке, что и исполняемый файл эмулятора
- `<platformName>.conf` – отдельный файл для каждой эмулируемой платформы, обычно находится в соответствующей подпапке

Конфигурационные файлы представляют собой текстовые файлы в кодировке UTF-8.

### Комментарии

Символ «#» рассматриваются как начало комментария, остаток строки от него и до конца строки игнорируется.

### Значения (литералы)

Значения могут иметь следующий вид:

- `1234` – десятичное число
- `0x12AB` – шестнадцатеричное число
- `строка` – строковая константа
- `"строка с пробелами"` – строковая константа
- `objectName` – имя объекта (глобальное)
- `&objectName` – ссылка на имя объекта (из той же платформы)
- `@VAR` – переменная (см. ниже)

### Перечень значений

Перечень значений представляет собой последовательность значений, разделенных запятыми, например:

```
rk, 1, 0x100, @FILE_NAME, "Имя файла", &obj
```

### Переменные

Объявление переменной и присвоение ей значения совмещены и имеют следующий вид:

```
@ИМЯ = значение
```

Значение может быть константой, другой переменной, либо перечнем значений

Для объявления пустой переменной может быть использован следующий синтаксис:

```
define NAME
```

Эта запись равнозначна следующей:

```
@NAME = ""
```

или

```
@NAME =
```

### Создание объектов

Оператор создания объектов имеет следующий вид:

```
TypeName objName [= перечень_значений]
```

(квадратные скобки обозначают необязательную часть оператора)

При этом создается объект типа TypeName с именем objName. Если для создания объекта требуются дополнительные параметры, то они указываются в перечне значений после знака «=».

Примеры:

```
Crt8275 crt
PartnerAddrSpace addrSpace = "partner/d14.bin"
ConfigRadioSelector scaleSelector = &window, frameScale, "Масштабирование"
```

В дальнейшем для ссылок на созданные объекты в том же файле используется следующий формат:

```
&objName
```

В глобальном конфигурационном файле знак «&» можно опускать.

### Присвоение значений свойствам объектов

Для присвоения значений свойствам объектов используется следующая запись:

```
objName.propertyName = список_значений
```

Например:

```
crt.dma = &dma, 2
addrSpace.range = &crt, 0xC000, 0xDFFF
```

Тот же синтаксис имеет вызов методов объектов, например:

```
config.addPlatform = "Партнер-01.01", "partner/partner.conf", "partner", "p"
```

### Связывание объектов

Начиная с версии эмулятора 4.0.503 появился новый механизм связывания выходов одного объекта с входами другого, имеющий следующий синтаксис:

```
connect objName.output -> objName.input
connect objName.output[index] -> objName.input
connect objName.output[from-to] -> objName.input
connect objName.output[…] -> objName.indexedInput(index)
```

Например:

```
connect zxPorts.portFE[0-2] -> crtRenderer.borderColor
```

### Условное выполнение

Для управления обработкой конфигурационного файла служат условные операторы, имеющие следующий синтаксис:

```
[ ifdef | ifndef VAR_NAME ] | [ if VAR_NAME [ == | != ] значение ]
  операторы 1
[ else
  операторы 2 ]
endif
```

В случае, если определена / не определена переменная VAR либо переменная VAR равна / не равна значению, выполняются операторы1, иначе – операторы2.

VAR_NAME указывается без начального «@». В случае указания «@» будет проверяться значение переменной, имя которой содержится в VAR_NAME.

Поддерживаются вложенные условные операторы.

### Включение файлов

Для включения другого файла служит директива include:

```
include имя_файла
```

Имя_файла можно указывать как непосредственно, так и с помощью переменной, содержащей имя файла:

```
@FILE_NAME = "filename"
include @FILE_NAME
```

## Описание типов объектов

### Глобальные типы

#### Emulation

Объект, представляющий собой основную часть эмулятора. Явное создание не требуется, заранее создан с именем «emulation». Имеет следующие свойства:

- **`frequency`** – внутренняя частота работы эмулятора в герцах. Рекомендуется устанавливать значение, равное наименьшему общему кратному всех частот, используемых эмулируемыми платформами. Значение по умолчанию – 560000000.

- **`maxFps`** – максимальная скорость обновления экрана, fps. Значение 0 соответствует отсутствию ограничений (максимальному fps). Значение по умолчанию – 100.

- **`sync`** = `yes | no`

  Значение yes служит для включения синхронизации с кадровой частотой видеоадаптера (по умолчанию). Может не поддерживаться некоторыми видеоадаптерами или драйверами либо может быть выключено в настройках драйвера.

- **`volume`** – громкость звука, может принимать значения от 1 до 7 (6 — максимальная рекомендуемая громкость, при значении 7 возможны щелчки и искажения звука).

- **`runPlatform`** = `имя_объекта_платформы`

  Запуск определенной платформы из предварительно созданного перечня. Если некоторая платформа была запущена через соответствующую опцию командной строки, все указания runPlatform игнорируются.

  В случае, если в глобальном конфигурационном файле отсутствуют вызовы runPlatform и не создаются явно объекты типа Platform (см. ниже), то при запуске эмулятора будет предложено выбрать запускаемую платформу из перечня.

- **`processCmdLine`** – обработка параметров командной строки. Должна вызываться после config.addPlatform и config.addExtention (см. ниже), но до runPlatform. Вызов не требует параметров.

#### EmuConfig

Объект, представляющий собой конфигурацию списка эмулируемых платформ. Явное создание не требуется, заранее создан с именем «config». Свойства:

- **`addPlatform`** = `Название, конфигурационный_файл, имя_объекта[, опция_командной_строки]`

  Добавление платформы в список доступных платформ. Параметры:
  - Название – имя платформы, отображаемое в перечне доступных платформ
  - Конфигурационный файл – путь к файлу описания платформы
  - Имя объекта – имя объекта, присваиваемое создаваемому объекту – платформе (модификации платформ задаются через точку, например `spec.lik`).
  - Опция командной строки (необязательный параметр) – опция командной строки, при указании которой будет автоматически запускаться данная платформа

- **`addExtention`** = `Расширение, имя_объекта`

  Ассоциирование расширений файлов с платформами. параметры:
  - Расширение – расширение имени файла
  - Имя объекта – имя объекта-платформы из добавляемых с помощью addPlatform

- **`runFileName`** = `Имя файла`

  Указывает имя файла, в который будет сохраняться информация о выбираемой при запуске платформе по умолчанию. Данный файл может быть включен в глобальный конфигурационный файл с помощью директивы `include`.

#### WavReader

Объект — проигрыватель wav-файлов. Явное создание не требуется, заранее создан с именем «wavReader». Свойства:

- **`channel`** = `left | right | mix`

  Указывает используемый канал в стерео-файлах (левый, правый, либо микс обоих каналов). Значение по умолчанию – mix. Для моно-файлов параметр игнорируется.

#### Platform

Объект – эмулируемая платформа. Для обращения к объекту типа Platform внутри файла конфигурации платформы служит предопределенное имя объекта "platform".

### Общие типы

#### EmuWindow

Объект – окно. Создание не требует дополнительных параметров. Имеет следующие свойства:

- **`caption`** = `заголовок_окна`

  Имя платформы, отображаемое в заголовке окна.

- **`defaultWindowSize`** = `ширина, высота`

  Размер окна в фиксированном режиме. Значения по умолчанию – 800, 600

- **`windowStyle`** = `autosize | resizable | fixed`

  Стиль окна. Может принимать следующие значения:
  - `autosize` – автоматическая подстройка размера окна
  - `resizable` – изменяемый пользователем размер
  - `fixed` – фиксированный размер, задаваемый свойством defaultWindowSize (см. выше)

  Значение по умолчанию – autosize.

- **`frameScale`** = `1x | 2x | 3x | 4x | 5x | 2x3 | 3x5 | 4x6 | fit | bestFit | fitKeepAR`

  Масштаб изображения в окне для стилей autosize и fixed. Игнорируется при использовании стиля sizeable. Возможные значения:
  - `1x – 5x` — масштабы 1:1 – 1:5
  - `2x3` — масштаб 2:1 по вертикали и 3:1 по горизонтали
  - `3x5` — масштаб 3:1 по вертикали и 5:1 по горизонтали
  - `4x6` — масштаб 4:1 по вертикали и 6:1 по горизонтали
  - `fit` – растягивание до размеров окна без сохранения пропорций
  - `fitKeepAR` – растягивание до размеров окна с сохранением пропорций
  - `bestFit` - растягивание до размеров окна с сохранением пропорций и целочисленным коэффициентом

- **`antialiasing`** = `yes | no`

  Установка режима сглаживания. Значение по умолчанию – no.

- **`fieldsMixing`** = `yes | no`

  Установка режима смешивания полукадров. Полезно в режимах экрана gigascreen. Значение по умолчанию – no.

- **`fullscreen`** = `yes | no`

  Установка полноэкранного режима. Значение по умолчанию – no

- **`aspectRatio`** = `1to1 | original`

  Управление параметром Aspect Ratio. Возможные значения:
  - `1to 1` – 1:1, квадратные пиксели в эмуляторе (по умолчанию)
  - `original` – в соответствии с картинкой на экране эмулируемого ПК

  В настоящее время поддерживается только режим PAL (756i).

#### ConfigTab

Объект – закладка в окне конфигурации. Работает только в SDL/wx-версии. При создании указывается единственный параметр – заголовок закладки:

```
ConfigTab configTab = "Заголовок"
```

Имеет следующее свойство-метод:

- **`addControl`** = `номер_столбца, &объект_ConfigRadioSelector`

  Добавляет в заданный столбец закладки окна конфигурации параметр, заранее определенный объектом типа ConfigRadioSelector (см. ниже). Всего доступны три столбца, задаваемых значениями 1, 2 и 3.

- **`optFileName`** = `Имя файла`

  Указывает имя файла, в который будут сохраняться настройки данной закладки. Данный файл может быть включен в конфигурационный файл с помощью директивы `include`.

#### ConfigRadioSelector

```
ConfigRadioSelector selector = &имя_объекта, имя_свойства, заголовок
```

Определяет объект – группу выбора значения в закладке окна конфигурации. Работает только в wx/sdl-версии. При создании указываются следующие параметры:

- имя объекта – имя связанного объекта
- имя свойства – имя свойства объекта, которым осуществляется управление
- заголовок – отображаемый заголовок в группе выбора значения

Имеет следующее свойство-метод:

- **`addItem`** = `значение_свойства, отображаемое имя`

  Например:

  ```
  scaleSelector.addItem = fit, "Растянуть во все окно"
  ```
