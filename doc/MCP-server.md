# MCP-сервер Emu80

## Что это такое

MCP (Model Context Protocol) — это протокол, позволяющий AI-ассистентам
(Claude Code, Claude Desktop и другим) взаимодействовать с запущенным
эмулятором Emu80. Ассистент может читать регистры и память,
устанавливать точки останова, управлять выполнением, делать скриншоты,
загружать файлы, эмулировать нажатия клавиш — всё, что доступно
пользователю через интерфейс эмулятора.

Сервер встроен непосредственно в Emu80 и работает в фоновом режиме.
Доступ к нему открыт только с локального компьютера (127.0.0.1).

## Сборка и запуск

MCP-сервер включается на этапе сборки. Необходимо собрать Emu80 с
определением `MCP_SERVER`:

```bash
qmake MCP_SERVER=1 src/Emu80qt.pro
mingw32-make -j4
```

Запустите собранный `Emu80qt-mcp.exe` — сервер стартует автоматически
на порту **19781**. GUI-отладчик в данной сборке в настоящее время
недоступен, отладка возможна только с помощью MCP-сервера.

## Подключение AI-ассистента

### Claude Code

```bash
claude mcp add --transport http emu80 http://127.0.0.1:19781/mcp
```

### Claude Desktop

Добавить в конфигурацию (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "emu80": {
      "url": "http://127.0.0.1:19781/mcp",
      "transport": "http"
    }
  }
}
```

## Инструменты

### Состояние системы

| Инструмент | Назначение |
|---|---|
| `cpu_state` | Состояние процессора: регистры (AF, BC, DE, HL, SP, PC), флаги (S/Z/H/P/N/C), IFF, регистры Z80, инструкция по адресу PC, состояние останова/паузы, количество тактов с последнего сброса |
| `regs_set` | Изменение регистров процессора (требует режима останова) |
| `sys_info` | Информация о сервере, текущей платформе, типе и частоте процессора, коэффициенте ускорения, списке доступных платформ |

### Управление выполнением

| Инструмент | Параметры | Назначение |
|---|---|---|
| `emu_run` | — | Продолжить выполнение |
| `emu_run_for` | `ms` (1–60000) | Выполнять заданное число миллисекунд. Останов по таймеру или точке останова. Возвращает полное состояние процессора |
| `debug_break` | — | Остановить процессор (также выводит из паузы) |
| `debug_step` | `mode` (`into`/`over`/`skip`), `timeout_ms` | Пошаговое выполнение. `skip` — пропустить инструкцию без выполнения |
| `emu_reset` | — | Холодный сброс |
| `emu_load` | `file`, `autorun`, `break_after_load` | Загрузить файл в эмулятор |
| `switch_platform` | `platform` | Переключиться на другую платформу |

### Память и порты

| Инструмент | Параметры | Назначение |
|---|---|---|
| `mem_read` | `addr`, `len` (1–4096) | Чтение памяти (hex-дамп + ASCII) |
| `mem_write` | `addr`, `data` (hex-строка) | Запись байтов в память |
| `port_read` | `port` (0–255) | Чтение байта из порта ввода-вывода |
| `port_write` | `port` (0–255), `value` | Запись байта в порт ввода-вывода |
| `disasm` | `addr`, `count` (1–64) | Дизассемблирование инструкций |

### Точки останова

| Инструмент | Параметры | Назначение |
|---|---|---|
| `bp_list` | — | Список всех точек останова |
| `bp_set` | `addr`, `type`, `skipCount`, `comment` | Установка точки останова. Типы: `exec` — код, `write`/`read`/`access` — память, `port_read`/`port_write`/`port_access` — порты |
| `bp_remove` | `addr`, `type` (необязательно) | Удаление точек останова. С фильтром по типу — выборочное |
| `bp_clear` | — | Удалить все точки останова |

### Экран

| Инструмент | Параметры | Назначение |
|---|---|---|
| `screen` | — | Скриншот экрана в формате PNG |
| `text_screen` | — | Текстовое содержимое экрана (UTF-8). Доступен только на платформах с текстовым режимом |

### Клавиатура

| Инструмент | Параметры | Назначение |
|---|---|---|
| `kbd_send` | `keys`, `action` (`press`/`release`/`tap`), `duration_ms` | Нажатие/отпускание/удержание клавиш. `tap` ждёт завершения или точки останова |
| `kbd_reset` | — | Сбросить все виртуально нажатые клавиши |
| `kbd_text` | `text` | Ввод текстовой строки через KbdTapper (зависит от платформы) |

### Диски

| Инструмент | Параметры | Назначение |
|---|---|---|
| `disk_attach` | `drive` (A–D или HDD), `file` | Подключить образ диска |
| `disk_detach` | `drive` (A–D или HDD) | Отключить образ диска |

## Формат чисел

Числовые параметры принимаются в двух формах:

- **JSON-число** — всегда десятичное. `6295` = 6295₁₀.
- **JSON-строка** — по умолчанию шестнадцатеричное. `"6295"` = 0x6295.
  - `"0x6295"` — явное шестнадцатеричное
  - `"0o3000"` — восьмеричное
  - `"06295"` — десятичное (ведущий ноль без x/o)

## Примеры

Получить состояние процессора:
```json
{"method": "tools/call", "params": {"name": "cpu_state", "arguments": {}}}
```

Установить точку останова на запись в память по адресу 0x8000 с пропуском 3 срабатываний:
```json
{"method": "tools/call", "params": {"name": "bp_set", "arguments": {"addr": "8000", "type": "write", "skipCount": 3}}}
```

Запустить выполнение на 500 мс:
```json
{"method": "tools/call", "params": {"name": "emu_run_for", "arguments": {"ms": 500}}}
```

Нажать и отпустить клавишу Enter:
```json
{"method": "tools/call", "params": {"name": "kbd_send", "arguments": {"keys": ["enter"], "action": "tap", "duration_ms": 100}}}
```
